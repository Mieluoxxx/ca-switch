# ca-switch - OpenCode 配置管理工具

OpenCode 配置管理工具，支持多 Provider 和 Model 管理

## 支持

- OpenCode

## 安装

```bash
cargo install ca-switch
```

## 使用

```bash
# TUI 交互式界面（默认）
ca-switch

# 其他
ca-switch backup   # 备份恢复
ca-switch status   # 查看状态
```

## 功能

- 🔄 多 Provider 配置管理
- 🤖 模型列表管理与站点检测
- 💾 WebDAV 云同步备份
- 🎨 现代化 TUI 交互界面
